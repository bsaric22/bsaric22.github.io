# Logotipi programa

SVG datoteke služe za prepoznavanje alata u osobnom portfoliju. Izvorni oblici ostaju sačuvani; siva boja primjenjuje se CSS filtrom u `assets/hero.css`. Logotipi i nazivi pripadaju njihovim vlasnicima.

- C++, C#, Unity, HTML5, CSS3, Azure, Photoshop, Premiere Pro, Figma, Python, Node.js, JavaScript, R, RStudio, Illustrator i PostgreSQL: [Devicon](https://github.com/devicons/devicon/tree/master/icons), varijante `plain`. Licenca: `LICENSE-devicon.txt`.
- Camunda: [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/camunda.svg).
- Microsoft Office: [Simple Icons 9.21.0](https://github.com/simple-icons/simple-icons/blob/9.21.0/icons/microsoftoffice.svg). Licenca zbirke Simple Icons: `LICENSE-simple-icons.txt` (CC0).
- Bizagi: [službeni logotip](https://www.bizagi.com/files/live/sites/bizagi/files/bizagi_logo.svg).
- Oracle APEX: [Oracleova oznaka APEX](https://static.oracle.com/cdn/fnd/gallery/2701.0.2/images/ico-apex.svg).
- IBM WebSphere: [Carbon Design System, WebSphere pictogram](https://github.com/carbon-design-system/carbon/blob/main/packages/pictograms/src/svg/websphere.svg). Licenca: `LICENSE-carbon.txt`.
